# Supervised Learning: Regression Collection

This repository contains various supervised learning regression models implemented in Python using Scikit-Learn.

## Projects Included:
1. **Simple Linear Regression**: Predicting outcomes using a single variable.
2. **Lasso Regression (L1)**: Regularization technique to prevent overfitting and perform feature selection.
3. **Ridge Regression (L2)**: (Coming soon/Included) Regularization to handle multicollinearity.

## Dataset
* **insurance.xls**: The primary dataset used for these models, focusing on predicting healthcare charges based on user attributes.

## How to Run
1. Clone this repository.
2. Ensure you have `pandas`, `numpy`, `matplotlib`, and `sklearn` installed.
3. Open the `.ipynb` files in Jupyter Notebook or Google Colab.
